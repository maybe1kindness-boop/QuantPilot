# QuantPilot — A 股选股与回测工作台

QuantPilot 是一套面向个人投资者的 A 股**选股 + 自选股跟踪 + 回测验证**系统：多策略选股引擎、自选股策略跟进、Web 可视化工作台与完整的数据管理链路。本仓库只包含选股与回测功能，全部数据来自公开行情接口，不接入任何交易通道。

## 🎯 选股策略库（核心）

内置 **20 余种选股策略**，覆盖形态突破、底部反转、K 线组合、指标共振、涨停启动等多个维度：

| 策略类型 | 策略名称 | 核心逻辑 | 适用场景 |
|---------|---------|---------|---------|
| 形态突破 | 仙人指路 | 冲高回落+长上影+反包 | 上升趋势中短线机会 |
| 均线突破 | 2560 战法 | 股价突破 MA25 + 均量金叉 | 趋势启动初期 |
| 形态反转 | W 底策略 | 双底形态+颈线突破 | 底部反转确认 |
| K 线组合 | 多方炮 | 两阳夹一阴 | 短线强势股 |
| 底部反转 | 底部趋势拐点 | 深度下跌+MACD 底背离+放量反弹 | 严重超跌后的反转 |
| 涨停策略 | 涨停回马枪 | 涨停后回调+缩量 | 二次启动机会 |
| 涨停策略 | 涨停横盘 | 涨停后横盘+突破信号 | 横盘突破 |
| K 线组合 | 启明星 | 三根 K 线底部反转 | 底部反转信号 |
| 指标共振 | 多金叉共振 | 均线+KDJ+MACD 金叉共振 | 多重指标确认 |
| 阻力突破 | 阻力位突破 | 放量长阳突破关键阻力 | 突破买入 |
| 洗盘策略 | 强势洗盘弱转强 | 放量上涨+洗盘+反包 | 强势股回调 |
| 趋势加速 | 趋势加速拐点 | 上升趋势+放量长阳 | 趋势加速确认 |

另有：金三角、金叉不绿、不死鸟、趋势共振反转、趋势启动等策略，以及：

- **形态库匹配**：基于 DTW 距离的历史形态相似度匹配（`pattern_library` / `pattern_matcher`）
- **策略并行执行**与**参数锁定追踪**（`parallel_strategy_executor` / `param_lock`）
- 每个策略配有说明书，见 `strategy/strategy_specifications.md`

## ⭐ 自选股跟踪

- 自选股清单管理（增删改、本地持久化）
- 自选股策略跟进：对关注列表按策略持续评分跟踪（狩猎场 / 跟踪页）
- 选股结果一键加入自选，历史选股记录可回看

## 🧪 回测验证

- **引擎级回测**：`trading/backtest_engine.py`，按策略参数在历史数据上复现选股信号
- **Web 回测页**：回测参数配置、任务历史、净值曲线
- **回测研究框架**：`backtest_2y/` 下 30+ 个独立研究脚本（多年回放、策略组合、参数扫描、Excel 报告生成）

## 🌐 Web 工作台

Flask + SocketIO 实时界面（默认端口 5001），16 个功能页：数据初始化 / 数据更新 / 选股执行 / 选股历史 / 结果分析 / 股票排行 / 排行跟踪 / 回测配置 / 回测历史 / 策略管理 / 自选跟踪等。

## 📊 数据层

- 多数据源自动降级：TickFlow → 腾讯财经（日线）、东财 → AKShare → 腾讯（实时行情），Tushare 可选
- 日线增量更新，全市场约 5200 只股票，SQLite 本地存储，建表脚本随仓库提供
- 网页端一键初始化：实时进度条、支持暂停/继续

## 快速开始

### 方式一：双击启动（推荐）

| 平台 | 启动文件 |
|------|---------|
| Windows | 双击 `start_web.bat` |
| macOS | 双击 `启动Web面板.command` |

- 首次双击会自动创建虚拟环境并安装依赖，之后启动很快
- 只需已安装 Python 3.10+（Windows 安装时勾选 *Add to PATH*）
- 建议通过 `git clone` 获取项目；若下载 ZIP，macOS 双击 `.command` 可能提示"未知开发者"，右键 → 打开 即可

### 方式二：命令行

```bash
# 1. 安装依赖 (Python 3.10+)
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# 2. 创建本地配置(不填钉钉 webhook 也能正常使用)
cp config/config.yaml.template config.yaml

# 3. 启动 Web 工作台
python3 web_server.py        # 浏览器打开 http://127.0.0.1:5001

# 或使用命令行流程
python3 main.py init         # 首次: 下载全市场历史数据(约1-3小时)
python3 main.py update       # 此后每日增量更新
python3 main.py run          # 执行选股
```

### 首次使用须知（重要）

1. **首次启动后请先初始化数据**：打开 Web 工作台 → 数据管理 → 点击「数据初始化」，自动下载全市场约 5200 只股票的基础信息与历史 K 线（视网络约 1~3 小时，有进度条，支持暂停/继续）
2. 初始化完成前，选股与回测因缺少历史数据，结果为空属正常现象
3. 之后每次使用会自动增量更新当日数据
4. 命令行 `python main.py update` 在空数据库上是空操作——**数据初始化必须先行**
5. 可选：在 `config/tushare_config.json` 中写入 `{"token": "你的token"}` 可启用 Tushare 数据源（免费注册），未配置时自动使用腾讯财经等免费源
